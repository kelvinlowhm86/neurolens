How to get your audience-retention report

YouTube keeps a real audience-retention curve for each of your own videos: how much of the audience is still watching at each point. You can add that curve to the analysis of a finished video in NeuroLens that you share for research. A valid curve can make that video's analysis free; the form says when.

Get the report

  1. Open Google's APIs Explorer for the YouTube Analytics API method reports.query: https://developers.google.com/youtube/analytics/reference/reports/query. The "Try it" section on that page opens the APIs Explorer.
  2. Sign in with the Google account that owns the channel, and allow read-only access when Google asks.
  3. Fill in these values:
    • ids: channel==MINE
    • startDate: the day the video was published, as YYYY-MM-DD
    • endDate: today, as YYYY-MM-DD
    • metrics: audienceWatchRatio
    • dimensions: elapsedVideoTimeRatio
    • filters: video== followed by the video's ID (the part after v= in its link)
  4. Run it.
  5. Copy the whole response and save it as a text file ending in .json.
  6. In NeuroLens, click "Add audience retention" on the finished video's row or result.

Things to know

  • Only the channel owner can get this report.
  • One video per request.
  • Leave out any other dimensions. Adding one gives repeated time points, and the form refuses them.
  • A response with no rows means YouTube has no data yet for the video. This happens with new videos or ones with very few views.
  • The file must be under 64 KB. A normal report is about 5 KB.

Written from the YouTube Analytics API documentation as of 15 October 2026; Google may change its tools.
