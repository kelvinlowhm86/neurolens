# Sample videos

This directory is gitignored (~155 MB of source ad creative).
`data/samples.json` ships pre-computed results for all of these, so the
dashboard renders its charts on a fresh clone — only video *playback* needs
the files below. Drop the .mp4s back in here to restore it.

The .wav and .tsv files are derived (ffmpeg / transcription) and are
regenerated as needed; only the .mp4s are required.
