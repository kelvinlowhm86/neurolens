# Sample videos

This directory is gitignored except this file and `SOURCES.md` (~71 MB of open-licensed clips).
`data/samples.json` ships pre-computed results for the two samples below, so the
dashboard renders its charts on a fresh clone — only video *playback* needs
the files below. Drop the .mp4s back in here to restore it. `SOURCES.md` records the sources and
licences.

## Expected filenames

```
bbb_720p_55s.mp4
sintel_trailer_720p.mp4
```

`_test_clips/` holds test clips, such as `sintel_loop_119s_480p.mp4` (the 119 s clip) and short
clips like `ok_27s.mp4`.
